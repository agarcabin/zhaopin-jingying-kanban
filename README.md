# 招聘经营看板（优化版）

面向大老板汇总展示、支持逐层下钻的招聘经营看板。数据与正式版《招聘综合工作台》同源（企微在线表格《创新招聘组数据》快照），口径与正式版完全一致。

在线地址：<https://agarcabin.github.io/zhaopin-jingying-kanban/>

## 设计思路

**第一层 · 汇总（老板视角，一屏讲清结果）**

1. 结果汇总：核实入职（主表口径）+ 面试通过 / 实际到面 / 发出邀约（批次口径）四张大数字卡片；
2. 过程指标条：触达曝光、互动沟通、收获简历、企微添加数；
3. 招聘漏斗：触达→沟通→简历→企微→邀约→到面→通过→入职，附入职后 1/3/7 天回访与待建层；上半场跨源仅作量级参考，邀约→到面→通过→入职为同一批登记人选的真实追踪，转化率可比；
4. 项目排行：客户条形图（条长=发出邀约，内嵌到面/通过/入职，标注「入职/邀约」）；
5. 人员业绩：按核实入职排序的到面/通过/入职条形图；
6. 逐日趋势：邀约、到面、通过、入职四条折线；
7. 数据待核对：到面待补、结果待补、通过未入职、试岗离职、回访待补自动汇总。

**第二层 · 模块明细（点击任意数字/条形/漏斗层打开弹窗）**

- 指标详情：指标口径说明 + 人员构成表 + 按日拆分；
- 阶段详情：批次状态分段条 + 人员构成 + 候选人级明细；
- 项目详情：项目四指标 + 参与人员表 + 岗位标签 + 候选人明细；
- 人员详情：个人六指标 + 邀约推进 + 参与项目 + 完整日报指标 + 候选人明细；
- 当日明细：日报矩阵 + 当日人员 + 当日登记候选人。

**第三层 · 交叉跳转**：弹窗内人员 ↔ 项目互相跳转，候选人明细表中人名、项目均可继续下钻。

## 可视化方案

- 图表库：Apache ECharts 5.5.0 本地部署（`assets/echarts.min.js`，许可证在 `assets/ECHARTS-LICENSE.txt`），无 CDN 依赖；堆叠条形图（项目排行）、分组条形图（人员排行）、折线图（趋势）均带 tooltip 与点击下钻。
- 漏斗采用自绘 HTML/CSS 沙漏层（延续正式版视觉语言），每层可点击，转化率与口径注释直接标注。
- 样式：商务看板风——冷灰底 + 白卡片 + 细边框（无渐变、无重投影），藏青为过程主色、朱红仅用于入职等关键结果与激活态；KPI 卡左侧色条区分指标类别，日期筛选为分段控件；图表用墨蓝梯度 + 朱红高亮，与页面同一套色板。响应式布局，支持打印与 `prefers-reduced-motion`。

## 数据来源与更新

数据文件 `data.json` 由 `scripts/build-data.mjs` 从正式版仓库的 `embeds/dashboard.html` 提取 `__DATA__` 快照生成（只读取、不修改正式版）：

```bash
node scripts/build-data.mjs   # 默认读取同级目录 ../recruitment-workspace
```

生成后提交推送即可更新线上看板。当前数据：2026-10-09 ~ 2026-11-12 共 35 天，9 名招聘专员，182 条邀约登记记录。

### AI 开发看板（ai-data.json）

滴答清单「AI 开发进度」文件夹的只读快照，字段与正式版 `data/ai-development.json` 同构（folder / capturedAt / projects[].tasks[]，含优先级、父子任务、检查项、完成时间）。更新方式与正式版一致：通过已授权的国内滴答 MCP 重新读取该文件夹的未完成任务，并调用 list_completed_tasks_by_date 按文件夹内全部项目查询已完成任务，按任务 ID 合并去重后覆盖 `ai-data.json`。前端只读快照，不直接调用滴答接口，不含任何凭据。

### 项目看板（project-data.json）

企微表格《合作项目情况表》「合作项目」子表的快照，分三部分：`projects`（正式合作项目，含岗位类别 / 主招 / 城市 / 负责业务 / 确认合作日期 / 费用 / 需求等）、`daily`（计天项目）、`following`（跟进项目）。更新方式：用已授权的 `wecom-cli` 读取该子表（`sheet cells get` 导出 CSV 后按「计天项目：」「跟进项目：」分区解析），覆盖 `project-data.json`。快照中不含联系人电话等敏感字段。

### 口径要点

- 邀约 / 到面 / 通过 / 批次入职 / 回访来自邀约登记批次（`invite_records`），按登记日期归组，状态为源文件最新记录；
- 核实入职（主表口径）按「入职日期」统计，试岗当天离职已排除；两者日期含义不同，不能直接相除；
- 触达、沟通、简历、企微为平台过程量，与邀约批次非同一批候选人，跨层转化率仅作量级参考；
- 候选人明细保留原名（与正式版一致，本仓库为公开仓库）。

## 文件

- `index.html`：页面结构（招聘 / AI开发 / 项目三个看板）
- `styles.css`：样式（设计 token + 响应式）
- `app.js`：聚合逻辑、图表渲染、弹窗下钻、页面切换
- `data.json`：招聘快照数据（由脚本生成，勿手改）
- `ai-data.json`：滴答清单 AI 开发进度快照
- `project-data.json`：企微表格合作项目快照
- `assets/`：ECharts 本地资源
- `scripts/build-data.mjs`：从正式版提取数据的构建脚本
